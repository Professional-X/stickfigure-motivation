How to set the thumbnail:
  Option A (manual, now): open the studio_edit URL above and upload
    the primary_thumbnail PNG from this repo
    (output/<run>/thumbnail.png or output/<run>/thumbnails/thumbnail_B.png).
  Option B (automate future runs): run get_youtube_oauth.py locally,
    add YOUTUBE_CLIENT_ID + YOUTUBE_CLIENT_SECRET + YOUTUBE_REFRESH_TOKEN
    as repo secrets, then re-trigger. Run scripts/backfill_thumbnails.py
    to set thumbnails on videos already uploaded.
